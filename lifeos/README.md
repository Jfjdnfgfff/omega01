# LifeOS — مدير حياتي الذكي

نظام شخصي لإدارة الحياة: الأهداف، المهام، الوقت، العادات، المشاريع، المال، الملاحظات والمراجعات — في تطبيق واحد.

> **ملاحظة عن المستودع:** هذا تطبيق مستقل تمامًا عن نظام **OMEGA GYM** الموجود في جذر المستودع.
> يعيش LifeOS داخل مجلد `lifeos/` بإعداداته وحزمته الخاصة، ولم يُعدَّل أي ملف من ملفات النظام القائم.

---

## التشغيل

```bash
cd lifeos
npm install
npm run dev        # http://localhost:3000
```

أوامر أخرى:

| الأمر | الوظيفة |
| --- | --- |
| `npm run test` | تشغيل مجموعة الاختبارات (Vitest) |
| `npm run typecheck` | فحص الأنواع (TypeScript) |
| `npm run build` | فحص الأنواع ثم بناء نسخة الإنتاج في `dist/` |
| `npm run preview` | معاينة نسخة الإنتاج |

## البنية

```
lifeos/
├── firestore.rules            قواعد أمان Firestore (عزل بيانات كل مستخدم)
├── .env.example               متغيرات البيئة (Firebase + مزوّد الذكاء الاصطناعي)
├── vitest.config.ts
├── src/
│   ├── types/                 نماذج البيانات (عقد واحد بين الطبقات)
│   ├── i18n/                  قاموسا العربية والإنجليزية
│   ├── lib/
│   │   ├── date.ts, currency.ts, id.ts, validation.ts
│   │   ├── domain/            منطق الحساب النقي (بلا React): goals, tasks, habits,
│   │   │                      projects, time, finance, reviews, dashboard, coach
│   │   ├── storage/           عقد التخزين + IndexedDB + Firestore + مصادقة محلية
│   │   └── store/             الحالة، الإجراءات، الإقلاع، التنبيهات
│   ├── components/            مكتبة الواجهة (ui, charts, layout, forms, time)
│   └── pages/                 الصفحات الإحدى عشرة
└── tests/                     97 اختبارًا: المنطق + التحقق + التخزين + اختبار دخان للواجهة
```

**فصل المنطق عن الواجهة:** كل رقم يظهر في التطبيق يُحسب في `src/lib/domain/*` من البيانات
المخزّنة، عبر دوال نقية قابلة للاختبار. المكوّنات لا تحتوي على حسابات.

## التخزين والمصادقة

| الحالة | ما يحدث |
| --- | --- |
| إعدادات Firebase موجودة في `.env` | مصادقة Firebase (بريد/كلمة مرور) + Cloud Firestore تحت `/users/{uid}/...` + مزامنة لحظية بين الأجهزة |
| لا توجد إعدادات | وضع محلي واضح للمستخدم: IndexedDB على الجهاز، بلا مزامنة سحابية، مع إمكانية التصدير |

- `firestore.rules` يمنع قراءة أو كتابة بيانات أي مستخدم آخر — الحماية في القاعدة لا في إخفاء الأزرار.
- لا توجد أي مفاتيح إدارية (Admin SDK) في الكود؛ إعدادات العميل العامة فقط، وتُقرأ من متغيرات البيئة.
- **LocalStorage يُستخدم فقط لتفضيلات العرض** (السمة/اللغة) لتفادي وميض عند التحميل. البيانات في IndexedDB أو Firestore.
- مفتاح الذكاء الاصطناعي يبقى في `sessionStorage` لهذه التبويب فقط ولا يُكتب في قاعدة البيانات.

### تفعيل Firebase

```bash
cp .env.example .env   # ثم املأ القيم من وحدة تحكم Firebase
```

ثم طبّق القواعد:

```bash
firebase deploy --only firestore:rules
```

## الأقسام

- **الرئيسية** — أهم 3 أولويات، المهام، تقدم الأهداف، سلسلة العادات، المشاريع النشطة، الوقت المستثمَر، ملخص مالي، تنبيهات محسوبة، وإضافة سريعة.
- **الأهداف** — موعد نهائي، أولوية، أفق زمني، مقياس نجاح بقيم رقمية، مراحل، وربط بالمهام والمشاريع. التقدم يُحسب من المهام والمراحل والمقياس، أو يدويًا.
- **المهام** — عرض اليوم/الأسبوع/الكل/المتأخرة، بحث وتصفية، تقدير مدة، ربط بهدف ومشروع، إعادة جدولة فردية وجماعية، وأهم 3 مهام يوميًا.
- **الوقت** — تقويم يومي وأسبوعي، اكتشاف التعارضات، مؤشر حِمل اليوم مقابل السعة، مؤقت Pomodoro يسجّل الوقت الفعلي، ملخص حسب المشروع/التصنيف، وبنّاء خطة يومية يحترم السعة ويُدخل فترات راحة.
- **العادات** — تكرار يومي/أسبوعي، تقويم التزام، السلسلة الحالية وأفضل سلسلة، نسبة الالتزام الأسبوعية والشهرية، وتحديد ما يحتاج انتباهًا. تسجيل اليوم بمعرّف حتمي فلا يتكرر.
- **المشاريع** — عرض قائمة ولوحة Kanban مع نقل المهام بين الحالات، نسبة إنجاز حقيقية من مهام المشروع، ملاحظات، سجل تحديثات، وتنبيه خطر الجدول.
- **المال** — دخل ومصروفات بتصنيفات، ميزانية شهرية مع إسقاط نهاية الشهر، أكثر الفئات إنفاقًا، مقارنة شهرية، أهداف ادخار، وعملة قابلة للتغيير (منها الدينار الجزائري DZD). **لا ربط بنكي ولا استيراد تلقائي.**
- **الملاحظات** — أفكار، يومية، دروس، قرارات، وملاحظات مشاريع، مع وسم وبحث وربط بالأهداف والمشاريع.
- **المراجعات** — مراجعة يومية بخمسة أسئلة، ومراجعة أسبوعية بأرقام محسوبة (المنجز مقابل المخطط، الوقت، الالتزام، التقدم) مع اقتراح أولويات. لا تقييم نفسي مُختلَق.
- **المساعد** — محرّكان منفصلان بوضوح: قواعد محلية محسوبة من البيانات (ومُعلَنة أنها ليست ذكاءً اصطناعيًا)، أو مزوّد متوافق مع OpenAI يُفعّله المستخدم بمفتاحه.
- **الإعدادات** — الملف الشخصي، اللغة (عربي/إنجليزي مع RTL)، السمة، المنطقة الزمنية، أول يوم في الأسبوع، العملة، الميزانية، Pomodoro، الخصوصية، تصدير/استيراد JSON، وحذف البيانات أو الحساب.

## قرارات أمان وصدق صريحة

- **لا ردود ثابتة مُدّعى أنها ذكاء اصطناعي.** بدون مفتاح يظهر بوضوح: «التكامل غير مفعّل»، وتُستخدم القواعد المحلية مع تمييز كل رد بمصدره (`ai` أو `rules`).
- **لا أرقام تجريبية.** إن لم توجد بيانات تظهر حالة فراغ صريحة بدل إحصائيات مخترعة.
- **منع التكرار عند إعادة المحاولة:** معرّف حتمي لسجلات العادات والمراجعات، ونافذة idempotency للطلبات الجارية والمتتابعة.
- **معالجة الفشل:** تحديث متفائل يتراجع عند فشل الحفظ، مع رسالة وحالة حفظ ظاهرة (يحفظ/محفوظ/فشل) ومؤشر انقطاع الشبكة.
