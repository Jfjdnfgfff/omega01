روابط مسارات JSON المباشرة (Direct JSON Endpoints)

يتم حفظ جميع المشتركين، الغيابات، والمنتجات وكافة البيانات تلقائياً في المسارات المباشرة بصيغة JSON:

/.json كامل البيانات (Root) /products.json المنتجات (30 منتج) /customers.json المشتركين /sales.json المبيعات /expenses.json المصاريف /credits.json الديون والكريدي /caisseLogs.json الخزينة والجرد /staffPayouts.json خلاص العمال /suppliers.json الموردين /v2.json مسار V2 المقسم
مُفعل ونشط محرك الأداء الفائق المطور (High-Speed Engine)
  • الكاش المحلي (Cache-First): إقلاع فوري خلال أقل من 15 مللي ثانية دون انتظار الشبكة.
  • الجلب بالدفعات (Pagination & Limits): تدفق مقيد لآخر 200 عملية لتفادي التحميل الزائد.
  • المزامنة التفاضلية (Delta Sync): استماع مجزأ لكل قسم لمنع إعادة تنزيل كامل قاعدة البيانات.
جلب عند الحاجة فقط

قواعد الفهرسة والأمان المحسنة (.indexOn Rules)

انسخ قواعد الفهرسة المحدثة أدناه والصقها في لوحة Firebase Console > Realtime Database > Rules لتسريع استعلامات البحث والتصفية وحذف أي تحذيرات أداء:

High-Performance .indexOn Rules
فتح صفحة القواعد 
{
  "rules": {
    ".read": true,
    ".write": true,
    "customers": {
      ".indexOn": ["startDate", "endDate", "phone", "status", "paymentStatus"]
    },
    "credits": {
      ".indexOn": ["date", "name", "phone"]
    },
    "sales": {
      ".indexOn": ["date", "customerId"]
    },
    "products": {
      ".indexOn": ["barcode", "category", "stockLocation"]
    },
    "expenses": {
      ".indexOn": ["date", "category"]
    },
    "caisseLogs": {
      ".indexOn": ["date", "type"]
    }
  }
}
